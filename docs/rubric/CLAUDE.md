> **5개 KPI**(사전준비도·정책생산력·실시간 압박력·성과전환력·사후책임성)로 평가한다.

> 수치 합산에서 분리해 표시 전용으로 변경. §9 참고.)
>

> - 두 모델 모두 Vercel AI Gateway를 통해서만 호출한다. 두 역할은 절대 맞바꾸지 않는다.

## 0. 이 문서를 읽는 Claude에게

이 파일은 평가 **작업 지침서**다. 회의록이 주어지면 아래 절차를 순서대로 실행한다.

1. `§1 데이터 검증` — 평가 가능 여부와 한계를 먼저 선언
2. `§2 신호 추출 역할`에 따라 회의록에서 구조화 신호를 추출
3. `§3 KPI 정의`의 산식대로 5개 KPI를 계산 — **모두 순수 코드, LLM 채점 없음**
4. `§4 이슈 지속 추적`(KPI5)만 Opus5로 회기간 의미 매칭 수행
5. `§5 금지사항` 및 N/A 규칙 점검 후 출력
6. `§6 출력 포맷`(표1 + 표2)으로 결과 제출

**절대 원칙**: 근거 없는 추정으로 신호를 만들지 않는다. 회의록에 없는 인용·제안·답변을 추출하지 않는다.
**절대 원칙 2**: 5개 KPI를 하나의 종합 순위점수로 합산하지 않는다. 항상 독립적으로 표시한다.

## 1. 데이터 검증 (반드시 선행)

평가 전 다음을 확인하고, 결과물 상단에 **한계 고지문**을 명시한다.

### 1.1 필수 확인 항목

| 항목 | 확인 내용 | 미충족 시 조치 |
|---|---|---|
| 회차 수 | 1회기 단독인가, 복수 회기인가 | 1회기면 "스냅샷"임을 명시. 지속성·이연 실적 등 추세 측정 불가 명시 |
| 발언자 비율 | 출석 의원 중 발언자 수 | 미발언 의원은 **"평가 불가(N/A)"**로 처리. 절대 0점 부여 금지 |
| 회의 단위 최소 표본 | 해당 회의에서 의사진행·비의원 발언을 제외한 **실질 발언 의원 수** | 1명 미만(즉 0명)이면 해당 회의 전체를 목록에서 제외한다(`backend/lib/queries/insights.ts`). v2.1부터 3→1로 완화 — 5분자유발언 참석자가 다수이고 안건 토의 참여자가 실제로 1명뿐인 회의(예: 264회 본회의 제2차)가 통째로 걸러지는 부작용이 있었다. 표본이 1명뿐인 회의를 회의 간 비교에 쓸 때는 그 한계를 감안해야 한다. |
| 부의된 안건 여부 | 해당 회의에 formally-tabled 안건이 1건 이상 있는가(5분자유발언 제외) | 안건이 전혀 없는 회의(예: 개회식)는 전체를 목록에서 제외한다(`backend/lib/queries/insights.ts`). |
| 발언체 종류 | 본회의 / 상임위 / 시정질문 / 특별 재무감사 | KPI3·4 신호 추출이 제한될 수 있음을 경고 |
| 발언 유형 | 5분 이상 발언 / 예산결산 심의 / 행정사무감사 / 조례 발안 설명 | 발언유형 분류 — 향후 UI/필터링용 |
| 질의응답 구조 | 해당 발언 직후, 다음 의원 턴이 나오기 전까지 집행부/사무국 턴이 실제로 존재하는가 | 없으면 KPI3(실시간 압박력)·KPI4(성과전환력)는 N/A. 발언유형이 아니라 이 구조 유무로 동적 판정 |
| 회의록 성격 | 최종본 / 초본(교정 전) | 임시회의록으로서 법적 효력 없음을 고지 |
| 의원 이름 표기 | 같은 의원이 회의마다 직함 포함 여부가 달라 다르게 표기될 수 있음(예: "부의장 임수환" vs "임수환") | `backend/lib/members/roster.ts`가 `Data/2026_거제시의원_당선자_명단.xlsx` 명단 기준으로 표시 시점에 정규화한다. 서로 다른 의원을 하나로 합치거나 반대로 쪼개지 않도록, 명단에 없는 이름은 원문 그대로 둔다. |

### 1.2 평가 제외 대상

- **의장·부의장이 의사진행봉 발언** — 사회 역할이므로 정책 평가 대상 아님
- **위원장 재선보고** — 통상 결과 나열이므로 개인 역량 지표 아님
- **의례적 인사말** — 감사 인사, 소감 등은 이슈 제기 없이 지속 집계 제외

## 2. 신호 추출 역할 정의

발언 원문(및 질의응답 구조가 있으면 뒤따르는 집행부 답변 원문)에서 아래 신호를 추출한다.
모두 **Sonnet 5**가 수행하는 구조화 추출 작업이며, 회의록에 명시적으로 나타난 내용만 추출한다.

### 인용 신호 (KPI1 사전준비도용)
발언 중 아래 4종 인용을 찾아 유형과 원문 발췌를 기록한다.

| 유형 | 인식 기준 |
|---|---|
| **L 법령조문** | 법률명 + 조·항 특정 ("관련 법에 따르면"은 불인정) |
| **S 공식통계** | 수치 + 기준연도/출처 명시 ("많은 주민들이"는 불인정) |
| **P 검증가능출처** | 지자체명 + 사업명 특정 ("타 지역에서는"은 불인정) |
| **F 현장확인** | 방문·사진·직접 관찰 언급 ("다시 방문 시행하면"은 불인정) |

> **정확성 검증 필수**: 인용된 조문이 실제로 존재하지 않거나(예: 없는 항을 인용), 인용된 통계가
> 명백히 오류인 것으로 판명되면 그 인용은 분자에서 제외한다(−1건 처리) — 인용을 많이 했다는
> 사실만으로 가점을 주지 않는다.

### 제안요소 신호 (KPI2 정책생산력용)
발언에 담긴 제안 각각에 대해 4요소(예산 규모·조달방안, 시기·착수시점, 담당 주체, 실행 방법)의
충족 여부를 기록한다. 제안이 0건이면 KPI2는 N/A.

### 질의응답 왕복 신호 (KPI3·4용)
§1.1 "질의응답 구조"가 있는 발언만 대상. 의원 질의 원문과 뒤따르는 집행부 답변 원문을 왕복
단위(round)로 묶어, 각 round마다:
- **답변등급**: 확답(시기/주체/방법 중 2개 이상 명시) / 조건부(조건부 약속) /
  회피("검토하겠습니다"·"노력하겠습니다"·"살펴보겠습니다" 류, 구체성 없음)
- **가산 태그**(표시 전용 — §3③ 참고, 수치에는 합산하지 않음): 모순포착(답변이 이전 진술과 모순됨을
  지적) / 패턴제시(단발이 아닌 반복 구조로 제시) / 쟁점고정(상대의 화제 전환을 차단하고 원 쟁점으로
  복귀) / 법근거제시(추궁 중 법령 조문 인용)

### 자기제기 이슈 신호 (KPI5용)
발언 중 의원이 스스로 제기한, 향후 추적 가능한 구체적 이슈(민원·요구·문제제기)를 짧은 설명으로
추출한다. 의례적 인사·단순 질의는 제외.

> ### ⚠️ 오해 방지 (매우 중요)
> 신호 추출은 **"의원이 비리 의심스러운가"를 판정하지 않는다.** 발언록에서 부패 정황이 발견된
> 경우, 그 대상은 **집행부 절차**이며 반드시 **"○○ 의원이 제기한 문제 제기"**로만 기록한다.
> 모순포착 태그는 **답변자(집행부)의 진술 간 모순**을 의원이 지적했다는 뜻이지, 의원 자신의
> 발언이 모순됐다는 뜻이 아니다.

## 3. KPI 정의 (5개, 회의록 텍스트 전용)

채점은 **발언 단위**로 신호를 추출하고(KPI1~4), **의원 단위**로 누적 집계한다(KPI5).
5개 KPI는 절대 하나의 종합점수로 합산하지 않는다 — 단위가 서로 달라 산술 결합이 부적절하다.

KPI 순서(인과 사슬): **①준비하는가 → ②논의를 이끄는가 → ③물고 늘어지는가 → ④답변을 받아내는가 → ⑤끝까지 가는가**

---

### ① 사전준비도 (Preparation Level, 구 근거밀도)

```
사전준비도 = (L법령조문 + S정량통계 + P검증가능선례 + F현장확인) 인용수 ÷ 발언 어절수 × 100
```

발언 어절수는 분모로만 쓴다(길게 말했다고 유리해지지 않도록 100어절 기준 정규화). 의례적
인사말(감사 인사·소개)은 이상적으로는 어절수에서 제외해야 하지만, 공백 분리 기반의 기계적
어절 계산으로는 완벽히 걸러낼 수 없다 — 이는 **알려진 근사**로 문서화하며 별도 NLP 전처리는
하지 않는다. §2의 정확성 검증 규칙(오류 인용 −1건)이 함께 적용된다.

| 사전준비도 | 등급 |
|---:|:---:|
| 3.0 이상 | A |
| 2.0–2.9 | B |
| 1.0–1.9 | C |
| 1.0 미만 | D |

---

### ② 정책생산력 (Policy Productivity, 구 대안구체성)

```
정책생산력 = Σ(대안별 충족 요소 수, 0~4) ÷ 대안 수
```

요소: 재원(예산 규모·확보방안·절감 논거) / 시기(착수·완료시점·우선순위) / 주체(담당 부서·기관
특정) / 방법(실행 수단의 구체적 명시). 발언 내 대안이 0건이면 **N/A**(0점 아님).

---

### ③ 실시간 압박력 (Real-time Pressure, 구 추궁심도)

```
추궁깊이 = 질의 1건당 평균 왕복(round) 턴 수
재질의율 = 답변 후 재질의한 건수 ÷ 총 질의 건수
```

가산 태그(모순포착+1.0/패턴제시+1.0/쟁점고정+0.5/법근거제시+0.5)는 **수치값에 합산하지 않고**
round마다 태그로만 표시한다 — 추궁깊이는 순수하게 왕복 턴 수다. §1.1 "질의응답 구조"가 없는
발언(순수 5분 이상 발언 등)은 **N/A**(0점 아님) — 추궁할 대상 자체가 없었다는 뜻이지 감시 능력이
없다는 뜻이 아니다.

---

### ④ 성과전환력 (Outcome Conversion, 구 답변확보율)

```
성과전환력 = Σ(round별 답변등급 점수) ÷ 총 질의 건수
확답 = 1.0 · 조건부 = 0.5 · 회피 = 0
```

③과 동일한 조건으로 질의응답 구조가 없으면 **N/A**.

> **회피 판정 예시(고정 패턴, 확답 요소 없이 이 표현만 있으면 회피)**: "검토하겠습니다",
> "노력하겠습니다", "살펴보겠습니다", "적극 반영하겠습니다", "고민해 보겠습니다".
> 이 표현이 있어도 시기/주체/방법 중 하나라도 구체적으로 딸려 있으면 확답 또는 조건부로 재분류한다.

---

### ⑤ 사후책임성 (Post-hoc Accountability, 구 이슈지속추적률)

```
사후책임성 = 후속 회기에서 재점검한 사안 수 ÷ 본인이 제기한 사안 수   (의원 단위 누적, 발언 단위 아님)
```

나머지 4개 KPI가 "1회성 스냅숏"인 데 반해, 이것만 여러 회기에 걸친 실제 추적을 측정한다.
새 이슈는 §2에서 추출된 대로 "이슈 티켓"으로 등록하고, 이후 회기에서 동일 의원의 새 이슈 후보가
기존 미해결 티켓과 §4의 방식으로 매칭되면 그 티켓을 "재검토됨"으로 표시한다.

| 사후책임성 | 등급 |
|---:|:---:|
| 60% 이상 | A |
| 40–59% | B |
| 20–39% | C |
| 20% 미만 | D |

이력이 3회기 미만으로 누적된 의원은 비율 대신 **"추적 중"**으로 표시한다(낮은 점수 아님).

---

### 부가 — 청렴 가산점 (독립 KPI 아님)

절차 위반 지적 + 법령 조문 특정(+1.0), 반복 패턴 제시(+1.0), 답변 모순 추궁(+0.5), 시정 조치
요구(+0.5)가 있으면 보조 배지로만 표시한다. 순위·등급에는 반영하지 않는다.

## 4. 이슈 지속 추적 — Opus 5 회기간 매칭 (KPI5 전용)

KPI5를 제외한 4개 KPI는 순수 코드로 계산되며 어떤 모델도 호출하지 않는다. Opus 5는 **오직**
"이번 회기 §2에서 추출된 새 이슈 후보가, 이 의원의 기존 미해결 이슈 티켓 중 하나와 동일 사안인가"
를 의미적으로 판단하는 데에만 쓰인다.

- 대상 의원에게 미해결(open) 이슈 티켓이 **없으면 Opus 5를 호출하지 않는다** — 비용 절감,
  KPI5는 자동으로 "추적 중" 또는 신규 티켓만 등록.
- Opus 5는 새 이슈 후보 설명과 기존 미해결 티켓 설명 목록을 받아, 매칭되는 티켓 ID(있다면)만
  반환한다. 표현이 다르더라도 같은 사안(같은 시설·같은 예산 항목·같은 정책)이면 매칭한다.
- 매칭되면 해당 티켓을 "재검토됨"으로 기록하고 새 이슈로는 등록하지 않는다. 매칭되지 않으면
  새 티켓으로 등록한다.
- **오판 방지**: 다른 의원이 제기한 이슈와는 절대 매칭하지 않는다(의원별로 티켓 목록을 분리
  조회). 확신이 낮으면 매칭시키지 말고 새 티켓으로 등록한다(거짓 재검토 방지가 거짓 신규보다 안전).

## 5. 금지사항 및 편향 방지

### 5.1 절대 금지

| # | 금지 항목 |
|---|---|
| 1 | 실명 개인에게 **"비리 의심" 딱지**를 부여하는 것 |
| 2 | 회의록에서 제기된 의혹을 **사실 확정으로 서술**하는 것 |
| 3 | 미발언 의원에게 **0점 또는 최하위 부여** (→ N/A 처리) |
| 4 | KPI1~4가 N/A인 발언에 임의의 점수를 매기는 것 — 규칙에 따라 N/A로 표기 |
| 5 | 5개 KPI를 **단순 산술평균**으로 통합해 종합점수를 만드는 것 — 항상 독립 표시 |
| 6 | 특정 정당·성별·정치(選好)를 점수에 반영하는 것 |
| 7 | 회의록에 없는 사실·수치를 보완·추정해 채우는 것 |
| 8 | 실명이 등장하는 민간 단체·업체를 **잠재 비리 주체로 지목**하는 것 |
| 9 | 다른 의원이 제기한 이슈를 본인이 제기한 것처럼 재검토 매칭하는 것 |
| 10 | 확신이 낮은 이슈 매칭을 강행해 실제로는 신규인 이슈를 "재검토됨"으로 잘못 표시하는 것 |

### 5.2 신호 추출 편향 통제 (v2.0에서 LLM 채점 제거로 자동 해소)

v2.0에서는 KPI1~4를 순수 코드로 계산하므로 LLM 채점 편향이 원천 차단된다. KPI5(이슈 매칭)만 Opus 5를 호출하며, 다음 규칙을 준수한다:

| 편향 | 통제 방법 |
|---|---|
| **발언자 정보 편향** | 이슈 매칭 시 **의원명을 마스킹**한 채 새 이슈와 기존 티켓의 의미적 유사성만 판단 |
| **확신 부족 시 과매칭** | 확신이 낮으면 매칭하지 말고 새 티켓으로 등록 — 거짓 재검토 방지가 거짓 신규보다 안전 |
| **의원 간 혼동** | 다른 의원의 티켓과 절대 매칭하지 않음 — 의원별로 티켓 목록 분리 |

### 5.3 결과물 표기 고지문

모든 산출물 상단은 다음을 포함한다.

```
본 평가는 [회차명] 회의록에 기반한 스냅숏이며,
의원의 전체 임기 활동에 대한 종합 평가가 아닙니다.
- 5개 KPI(사전준비도·정책생산력·실시간 압박력·성과전환력·사후책임성)는 독립적으로 표시되며,
  하나의 종합 순위점수로 통합되지 않습니다.
- KPI1~4가 N/A인 경우, 발언의 질이 낮다는 뜻이 아니라 해당 KPI를 측정할 신호가 없었다는 뜻입니다.
  예: 질의응답 구조가 없는 5분 발언은 KPI3·4가 N/A이지만, 이는 추궁 기회가 없었다는 의미입니다.
- KPI5(사후책임성)가 "추적 중"으로 표기된 의원은 누적 회기가 3회 미만으로, 추적 패턴을 판단할 데이터가 부족합니다.
- 미발언 의원은 평가 대상에서 제외(N/A)되었으며 점수가 아닙니다.
- 회의록에서 제기된 의혹은 해당 의원의 문제 제기일 뿐, 상대방이 확인된 사실이 아닙니다.
```

### 5.4 공표 전 절차

1. **신호 추출 검증**: 표본 회의록에 대해 Sonnet 5 추출 결과를 인간이 검증 → 재현성 확인
2. **이슈 매칭 검증**: KPI5 Opus 5 매칭 결과를 인간이 독립 검토 → 위양성(거짓 재검토) 여부 확인
3. **법률 검토**: KPI5 결과 공표 시 특정 의원의 추적 이력이 드러날 수 있음을 고려.
   의원별 이슈 티켓 목록 공개 여부에 대해 변호사 자문 필수
