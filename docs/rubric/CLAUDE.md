## 0. 이 문서를 읽는 Claude에게

이 파일은 평가 **작업 지침서**다. 회의록이 주어지면 아래 절차를 순서대로 실행한다.

1. `§1 데이터 검증` — 평가 가능 여부와 한계를 먼저 선언
2. `§2 에이전트 역할`에 따라 4개 관점으로 독립 분석
3. `§3 평가축 루브릭`을 앵커 기준으로 밴드 단위 채점
4. `§4 가중치`를 발언유형에 맞게 적용 — **단순평균 금지, 반드시 가중평균**
5. `§5 금지사항` 및 지속성 축의 N/A 규칙 점검 후 출력
6. `§6 출력 포맷`(표1 + 표2)으로 결과 제출

**절대 원칙**: 근거 없는 추정으로 점수를 매기지 않는다. 회의록에 없는 사실을 만들지 않는다.
**절대 원칙 2**: 개별 축을 단순 산술평균하지 않는다. §4 가중치표를 적용한 가중평균만 최종 점수로 인정한다.

## 1. 데이터 검증 (반드시 선행)

평가 전 다음을 확인하고, 결과물 상단에 **한계 고지문**을 명시한다.

### 1.1 필수 확인 항목

| 항목 | 확인 내용 | 미충족 시 조치 |
|---|---|---|
| 회차 수 | 1회기 단독인가, 복수 회기인가 | 1회기면 "스냅샷"임을 명시. 지속성·이연 실적 등 추세 측정 불가 명시 |
| 발언자 비율 | 출석 의원 중 발언자 수 | 미발언 의원은 **"평가 불가(N/A)"**로 처리. 절대 0점 부여 금지 |
| 회의 단위 최소 표본 | 해당 회의에서 의사진행·비의원 발언을 제외한 **실질 발언 의원 수** | 3명 미만이면 해당 회의 전체를 목록에서 제외한다(`backend/lib/queries/insights.ts`). 표본이 너무 작아 회의 단위 비교가 의미 없다고 판단되는 하한선이며, 근거 없이 임의 조정하지 않는다. |
| 발언체 종류 | 본회의 / 상임위 / 시정질문 / 특별 재무감사 | 본회의만 있으면 견제력 축이 과소평가됨을 경고 |
| 발언 유형 | 5분 이상 발언 / 예산결산 심의 / 행정사무감사 / 조례 발안 설명 | 유형별 가중치(§4) 적용 |
| 회의록 성격 | 최종본 / 초본(교정 전) | 임시회의록으로서 법적 효력 없음을 고지 |
| 의원 이름 표기 | 같은 의원이 회의마다 직함 포함 여부가 달라 다르게 표기될 수 있음(예: "부의장 임수환" vs "임수환") | `backend/lib/members/roster.ts`가 `Data/2026_거제시의원_당선자_명단.xlsx` 명단 기준으로 표시 시점에 정규화한다. 서로 다른 의원을 하나로 합치거나 반대로 쪼개지 않도록, 명단에 없는 이름은 원문 그대로 둔다. |

### 1.2 평가 제외 대상

- **의장·부의장이 의사진행봉 발언** — 사회 역할이므로 정책 평가 대상 아님
- **위원장 재선보고** — 통상 결과 나열이므로 개인 역량 지표 아님
- **의례적 인사말** — 감사 인사, 소감 등은 이슈 제기 없이 지속 집계 제외

## 2. 에이전트 역할 정의

4개 에이전트는 **동일 발언을 각자의 관점으로 독립 분석**한 뒤 통합한다.
서로의 결론을 참조하지 말고 병렬로 수행한다.

### agent1 — 정책설계 전문가
- **본다**: 아이디어의 독창성, 문제 정의의 정확성, 정책 논리의 인과관계
- **묻는다**: 이 발상이 다른 지자체 복사인가, 지역 맥락으로 재해석되었는가? 문제 제기와 해법이 논리적으로 연결되는가?
- **담당 축**: ① 창의성, ⑥ 시민체감(공동), ⑧ 거제발전, ⑦ 미래전략

### agent2 — 행정 전문가
- **본다**: 예산 규모·재원, 소관 부서, 인허가 절차, 집행 기간, 조직 구조
- **묻는다**: 실제로 집행 가능한가? 상위기관 법령 위임 사항을 요구하고 있지 않은가? 부서 간 중복·분산을 지적하는가?
- **담당 축**: ② 실현가능성, ⑥ 시민체감(공동)

### agent3 — 법률 전문가
- **본다**: 법령·조례·시행령 인용의 정확성, 상위법 저촉 여부, 권한 배분(국가/도/시)
- **묻는다**: 인용 조문이 실존하고 맥락에 맞는가? 지방자치단체 사무 범위 내인가? 통계 출처가 검증 가능한가?
- **담당 축**: ③ 근거·법적
- **특칙**: 인용 조문이 **허구(존재하지 않음)이거나 오용**이면 해당 축 상한 2점

### agent4 — 비리 전문가 (청렴 감시 전문가)
- **본다**: 예산 편취·집행 절차 우회, 이해관계·공모 누락, 특정 단체 반복 언급, 목(目) 변경, 이해충돌 정황
- **묻는다**: 의원이 이러한 리스크를 **포착하고 추궁하는가**? 단발 지적인가, 구조적 패턴 제시인가? 후속이 담보되는가?
- **담당 축**: ⑤ 견제력, **④ 지속성(신설, agent4가 최초 점수 초안 작성 후 agent2와 교차확인)**

> ### ⚠️ agent4 역할 오해 방지 (매우 중요)
> agent4는 **"어느 의원이 비리 의심스러운가"를 판정하지 않는다.**
> 발언록만으로 제3자 비위 의혹을 사실 확정처럼 서술하는 것은 근거가 없고 명예훼손 위험도 크다.
>
> agent4의 임무는 **"의원이 감시 주체로서 얼마나 기능하는가"**를 평가하는 것이다.
> 즉 의원은 **의혹의 대상이 아니라 감시의 주체**로 평가된다.
>
> 발언록에서 부패 정황이 발견된 경우, 그 대상은 **집행부 절차**이며,
> 반드시 **"○○ 의원이 제기한 문제 제기"**로만 기록하고 사실 판정으로 임의 확정하지 않는다.

## 3. 평가축 루브릭 (8축 · 5점 척도)

채점은 **발언 단위**로 하고, 세션별로는 **가중평균**을 집계한다.
(통짜 채점은 이후 세션에 좌우되므로 금지)

축 순서: **① 창의성 → ② 실현가능성 → ③ 근거·법적 → ④ 지속성 → ⑤ 견제력 → ⑥ 시민체감 → ⑦ 미래전략 → ⑧ 거제발전**

---

### ① 정책 창의성 — agent1

기존에 없는 관점·연결·해법인가.

| 점수 | 기준 |
|:---:|---|
| **5** | 지역 고유 자원·역사·산업을 재해석해 타 지역이 복제 불가능한 발상을 제시 |
| **4** | 타 사례를 가져오되 지역 조건에 맞게 변형·적용. 새로운 연결고리 존재 |
| **3** | 기성 정책 대안·정부 사업의 지역 이구. 지역 특화 설계 부여 |
| **2** | 일반적 민원 전달 또는 통상적 개선 요구 |
| **1** | 문제 제기만 있고 발상이라 부를 내용 없음 |

> **주의**: 예산 지출·행정 사무감사는 창의성 축이 구조적으로 낮게 나온다.
> 이는 역량이 아니라 **발언 형식의 특성**이므로, §4 가중치에서 제외 처리한다.

---

### ② 실현가능성 — agent2

예산·소관·절차·기간을 고려할 때 실제 집행 가능한가.

| 점수 | 기준 |
|:---:|---|
| **5** | 재원 조달 방안 또는 기존 사업 활용법 제시 + 소관 권한 확인 + 즉시 착수 가능 항목 포함 |
| **4** | 방향은 타당하고 소관도 있으나 재원·일정 명시 일부 미비 |
| **3** | 취지는 옳으나 예산 규모·주체가 불분명 |
| **2** | 소관 권한 및 재원의 권한 구조 언급 없이 요구 |
| **1** | 법령·재정적으로 진행 불가능한 요구 |

**가점 요소**
- 대규모 요구에 소규모 증액안 항목을 **단계화**한 경우
- 예산 **증액이 아닌 절감·재배분** 방향을 제시한 경우
- 상위 기관(도/국가) 권한임을 인정하고 우회 경로를 제시한 경우

---

### ③ 근거·법적 타당성 — agent3

| 점수 | 기준 |
|:---:|---|
| **5** | 법령을 **조문 단위(조·항)**로 정확히 특정 + 출처 있는 통계 2건 이상 + 검증 가능한 선례 |
| **4** | 구체적 통계·수치 다수 인용하는 법령 인용이 있거나 객관적 |
| **3** | 수치를 언급하는 출처·집계 기준 불명 |
| **2** | 법령 인용이 부정확하거나 맥락에 맞지 않음 |
| **1** | 근거 없이 정서·인상에 의존 ("주민들이 그러던데요") |

**즉시 감점**
- 존재하지 않는 법령·조문 인용 → **상한 2점**
- 사실과 다른 통계 인용 → **상한 2점**
- 정량 수치 0건 → **상한 3점**

---

### ④ 지속성 — agent4 (agent2 교차확인) · 신설

**동일 사안에 대해 이전 회기·이전 발언의 문제 제기를 이번 발언에서도 끈질기게 추적·재확인하는가.**
1회성으로 이슈만 던지고 끝나는 발언과, 답변 이행 여부를 회기를 넘겨 압박하는 발언을 구분하기 위한 축이다.

| 점수 | 기준 |
|:---:|---|
| **5** | 이전 회기(1회 이상)부터 동일 사안을 지속 추적하며, 구체적 이행 여부·기한·담당부서까지 재확인·압박 |
| **4** | 이전 발언을 명시적으로 인용해 진행상황을 재질의 (이행 확인은 있으나 구체성은 다소 낮음) |
| **3** | 과거 유사 발언을 언급하나 이행 확인 없이 일반적으로 재강조 |
| **2** | 이번 회기 내에서만 반복 강조하거나, 이전 회기와의 연결고리가 약함 |
| **1** | 최초 제기이며 후속 추적 계획·근거 언급이 없음 |
| **N/A** | **일회성 단순 질의·민원 전달**로, 추적 여부를 판단할 근거 자체가 없는 경우. 점수 대신 **"향후 발언평가내용"**으로 표기(§5.1 참조) |

> **핵심 규칙**: 다음 회기 이후 발언에서 같은 사안이 다시 등장하는지가 이 축의 최종 검증 기준이다.
> 단일 회기 데이터만으로는 4~5점을 함부로 부여하지 않는다 — 근거는 "이전 회기 인용"이어야 하며,
> 이전 회기 인용이 전혀 없는 신규 이슈 제기는 최대 1점, 그마저도 판단 근거가 부족하면 N/A로 처리한다.

---

### ⑤ 견제력 — agent4

| 점수 | 기준 |
|:---:|---|
| **5** | 구체적 절차 위반 사실 지적 + 법령 조문 특정 + **반복 패턴 제시** + 답변 모순 추궁 + 시정 조치 요구 |
| **4** | 구체적 사실과 법적 근거를 들어 추궁했으나 패턴화나 후속 답변 확보는 미흡 |
| **3** | 예산 집행·민간위탁 사안을 **정성 경계**했으나 특정 사업 추궁은 없음 |
| **2** | 공약 미이행·사업 지연 등 이행 점검 수준에 그침 |
| **1** | 해당 발언에 감시·견제 요소 자체 없음 |

> ### 📌 ⑤축 1점의 의미 (오해 방지 · 반드시 병기)
> **1점은 "청렴하지 않다"는 뜻이 아니다.**
> "이번 발언에서 감시 기능을 수행할 사안을 다루지 않았다"는 뜻이다.
> 5분 이상 발언은 본래 정책 제안이 목적이므로 대부분 1~2점이 정상이다.
> 결과 공표 시 이 문장을 **반드시 함께 표기**한다.

---

### ⑥ 시민체감 학습 — agent1 + agent2

| 점수 | 기준 |
|:---:|---|
| **5** | 다수 시민이 **즉시·직접** 체감. 대상 규모가 데이터로 입증됨 |

**⑧이 "공간적 범위"라면 ⑦은 "시간적 시계(視界)"다.**

**평가 요소**

## 4. 발언 유형별 가중치

동일 주제라도 5분 이상 발언과 예산 심의를 비교하는 것은 불변하다.
**유형별로 축을 가중하고 든다.**

| 축 | 5분 이상 발언 | 예산·결산 심의 | 행정사무감사 | 조례 발안 설명 |
|---|:---:|:---:|:---:|:---:|
| ① 창의성 | **1.5** | ―(제외) | 0.5 | 1.5 |
| ② 실현가능성 | 1.5 | 1.0 | 1.0 | **2.0** |
| ③ 근거·법적 | 1.5 | **2.0** | **2.0** | **2.0** |
| **④ 지속성(신설)** | **1.0** | **2.0** | **2.5** | **2.0** |
| ⑤ 견제력 | 0.5 | **2.0** | **2.5** | 0.5 |
| ⑥ 시민체감 | **1.5** | 1.0 | 1.0 | 1.5 |
| ⑦ 미래전망 | **1.5** | 1.0 | 1.0 | 1.5 |
| ⑧ 거제발전 | 1.0 | 0.5 | 0.5 | 1.0 |

> ④ 지속성은 "이전 내용에 대한 끈질긴 해결노력"에 직접 대응하는 축이므로,
> 행정사무감사(2.5)·예산결산 심의(2.0)·조례 발안(2.0)에서 근거·법적·견제력과 동급의 **상위 가중치**를 부여한다.
> 5분 이상 발언은 회기 내 최초 제기 성격이 강해 상대적으로 낮은 1.0을 부여한다.

**산출식 (필수 — 절대 단순평균으로 대체하지 않는다)**
```
가중평균 = Σ(축 점수 × 적용 가중치) / Σ(적용 가중치)
```

**집계 규칙**
- 의원이 여러 유형으로 발언한 경우, **유형별로 따로 산출한 뒤 별기**한다 (단순 평균 금지)
- 단순 산술평균 값은 **참고용**으로도 제시하지 않는다 — 이전 버전(v1.0)의 §7.2 예시가 "단순평균"이라는 라벨로 가중치 없이 산술평균을 표기한 것은 §4의 가중치 정의와 모순되는 오류였다. v1.1부터는 표1의 마지막 열이 항상 실제 가중평균이다.
- "―(제외)" 축과 ④ 지속성이 N/A("향후 발언평가내용")인 경우, 해당 축은 **분자·분모 모두에서 제외**하고 나머지 적용 가중치 합으로 나눈다.

## 5. 금지사항 및 편향 방지

### 5.1 절대 금지

| # | 금지 항목 |
|---|---|
| 1 | 실명 개인에게 **"비리 의심" 딱지**를 부여하는 것 |
| 2 | 회의록에서 제기된 의혹을 **사실 확정으로 서술**하는 것 |
| 3 | 미발언 의원에게 **0점 또는 최하위 부여** (→ N/A 처리) |
| 4 | ④ 지속성 축에서 **이전 회기 인용 근거가 없는데도 1점보다 낮은 임의 점수**를 매기는 것 — 반드시 **"향후 발언평가내용"**으로 표기 |
| 5 | 축별 점수를 **단순 산술평균**으로 집계해 가중평균인 것처럼 제시하는 것 |
| 6 | 특정 정당·성별·정치(選好)를 점수에 반영하는 것 |
| 7 | 회의록에 없는 사실·수치를 보완·추정해 채우는 것 |
| 8 | 실명이 등장하는 민간 단체·업체를 **잠재 비리 주체로 지목**하는 것 |

### 5.2 LLM 편향 통제

| 편향 | 통제 방법 |
|---|---|
| **긴 발언 편향** | 발언 길이가 아닌 **논거 밀도**로 평가. 형식 점수를 100자당 근거 인용수로 정규화 |
| **정당·인지도 편향** | **채점 전 이름·정당·지역구를 마스킹**하고 익명 텍스트로 채점 → 사후 매칭 |
| **위치 편향** | 발언 순서(첫 번째/마지막)가 점수에 영향을 주지 않도록 순서를 무작위화해 재검증 |
| **주제 편향** | 관광·문화 주제가 창의성에서 구조적으로 유리하므로, **동일 유형·동일 주제군 내 상대평가**를 병행 |
| **첫인상 고정 편향** | ④ 지속성을 과거 회기 없이 5점 만점 부여하지 않는다 — 반드시 이전 회기 인용 문구를 원문에서 인용해 근거로 첨부 |

### 5.3 결과물 표기 고지문

모든 산출물 상단은 다음을 포함한다.

```
본 평가는 [회차명] 회의록에 기반한 스냅숏이며,
의원의 전체 임기 활동에 대한 종합 평가가 아닙니다.
- ⑤ 견제력 1점 "청렴하지 않음"이 아니라
  "해당 발언은 감시 사안을 다루지 않았음"을 의미합니다.
- ④ 지속성이 "향후 발언평가내용"으로 표기된 항목은 이전 회기 데이터가 없어
  판단을 유보한 것이며 낮은 점수를 의미하지 않습니다.
- 미발언 의원은 평가 대상에서 제외(N/A)되었으며 점수가 아닙니다.
- 회의록에서 제기된 의혹은 해당 의원의 문제 제기일 뿐,
  상대방이 확인된 사실이 아닙니다.
- 표1/표2의 가중평균은 §4 가중치표에 의한 것이며 단순평균이 아닙니다.
```

### 5.4 공표 전 절차

1. **인간 검증**: 평가자 2~3인이 표본을 독립 채점 → 일치도 측정(Krippendorff's α ≥ 0.67 권장)
2. **법률 검토**: 제출자 평가 결과 공표가 명예훼손 관련 법령 저촉 가능성이 있음.
   특히 **지속성·견제력 축 비교표가 공표 시 인격권 비교 시안**이 될 수 있음을 반드시 확인. 변호사 자문 필요
3. **국핏 대상**: 세부 가중치는 비공개하거나 주기적으로 조정. 공개 시 짜맞춤 평가에 악용될 우려

### 7.5 구조적 발견 (개인 역량이 아닌 이슈 구조 문제)

1. **1조 4,305억 원 추경 심의에 본회의 질의자 1인 · 토론자 0인 · 안건 처리 13분.**
   실질 심의가 원안·의결서에 종결되는 관행으로 추정.
   → **의원 개인 발언 이전에 ⑤ 견제력 축의 절대 점수가 심각하게 왜곡됨.**
2. **⑦ 미래전략 평균 3.29** — 인구 감소·조직 우선순위 등 거제시 구조적 과제를 정면으로 다룬 발언은 1건(이화영)에 그침.
3. **④ 지속성이 전원 N/A인 것 자체가 발견이다** — 이는 회의록 부족이 아니라, 시스템이 아직 1개 회기 데이터만 보유했기 때문이다. **후속 회기 데이터가 누적되면 이 열이 실제로 채워지는지가 시스템 검증 기준이 된다.**
4. **⑤과 ⑧의 상관**: 지역구 밀착 의원(장미란·김미영)은 ⑥ 시민체감이 높고 ⑤⑦이 낮은 반대 패턴.
   이는 결함이 아니라 **역할 분업**일 수 있으므로 단일 서열로 뭉개지 말 것.
